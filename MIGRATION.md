# pnpm + Turborepo Migration — Implementation Plan

## Background

This project (`graphql-course-starter`) was originally a flat single-package npm app with all frontend and backend code sharing one root `package.json`. A `pnpm-workspace.yaml` and a `workspace:*` dependency (`@myorg/utils`) had already been added but the actual workspace directory structure did not exist.

This plan documents the full migration to a **pnpm + Turborepo monorepo**.

---

## Goal

Convert the project from a flat npm app into a proper pnpm workspace monorepo with:

- Turborepo orchestrating tasks across workspaces
- `apps/client` — React frontend (react-scripts)
- `apps/server` — Express + Apollo GraphQL backend
- `packages/utils` — shared utility library stub

## Changes Made

### Root

| File | Change |
| --- | --- |
| `package.json` | Replaced — stripped to workspace shell with only `turbo` as a devDependency and top-level `dev`, `build`, `test`, `codegen` scripts |
| `turbo.json` | Created — defines task pipeline for `start`, `build`, `test:fe`, `test:be`, `codegen`, `seed`, `migrate` |
| `.gitignore` | Updated — removed leading `/` from `node_modules`/`coverage`/`build` patterns (so they match all workspace subdirectories), added `.turbo` and `pnpm-debug.log*`, changed `.dev.db` to `*.db` glob |
| `package-lock.json` | Deleted — replaced by `pnpm-lock.yaml` |
| `pnpm-lock.yaml` | Generated by `pnpm install` |
| `src/` | Moved → `apps/client/src/` |
| `public/` | Moved → `apps/client/public/` |
| `server/` (contents) | Moved → `apps/server/` |
| `codegen.ts` | Moved → `apps/client/codegen.ts`; schema path updated from `./server/**` to `../../apps/server/**` |
| `jest.fe.config.js` | Moved → `apps/client/jest.fe.config.js` |
| `jest.be.config.js` | Moved → `apps/server/jest.be.config.js`; `testMatch` simplified to `**/*.test.ts` (already scoped to server workspace) |
| `tailwind.config.js` | Moved → `apps/client/tailwind.config.js` |
| `postcss.config.js` | Moved → `apps/client/postcss.config.js` |
| `tsconfig.json` | Moved → `apps/client/tsconfig.json` |

## `turbo.json` Task Pipeline

```json
{
  "tasks": {
    "build":    { "dependsOn": ["^build"], "outputs": ["build/**", "dist/**"] },
    "start":    { "cache": false, "persistent": true },
    "test:fe":  { "cache": false },
    "test:be":  { "cache": false },
    "codegen":  { "outputs": ["src/**/__generated__/**", "src/types/graphql.ts", ...] },
    "seed":     { "cache": false },
    "migrate":  { "cache": false }
  }
}
```

## Known Warnings (Pre-existing)

These warnings existed before the migration and were not introduced by it:

- `@types/node@^16` does not satisfy peer requirement `>=18` from `msw` and `@graphql-codegen/cli`  
  → Fix: bump `@types/node` to `^18` in `apps/client/package.json`
- `jest-fixed-jsdom` requires `jest-environment-jsdom@>=28` but `jest@27` is installed  
  → Pre-existing version constraint in the original project
- Various deprecated transitive subdependencies from `react-scripts` — also pre-existing

## Verification Steps

```bash
# 1. Confirm all 4 workspaces are recognised
pnpm ls -r --depth -1

# 2. Install fresh (already done)
pnpm install

# 3. Start both apps via turbo
pnpm dev

# 4. Run frontend tests
pnpm --filter @graphql-course/client run test:fe

# 5. Seed DB and run backend tests
pnpm --filter @graphql-course/server run test:be

# 6. Run graphql codegen
pnpm --filter @graphql-course/client run codegen
```
